# Pokémon World

เว็บแอปพลิเคชันที่แสดงผลในรูปแบบการ์ดที่สวยงาม ค้นหาง่าย และสลับหน้าดูข้อมูลได้อย่างลื่นไหล รองรับการแสดงผลสมบูรณ์แบบบนทุกอุปกรณ์

> 🌐 **Live Demo:** [https://pokemon-app-two-gamma.vercel.app/](https://pokemon-app-two-gamma.vercel.app/)

## รายละเอียดโปรเจกต์

โปรเจกต์นี้จัดทำขึ้นเพื่อเรียนรู้และฝึกฝนการพัฒนาเว็บแอปพลิเคชันฝั่งหน้าบ้าน รองรับการแสดงผลบนทุกอุปกรณ์อย่างไม่มีข้อจำกัด
